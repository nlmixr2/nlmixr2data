# Multiple dose theophylline PK data

This data set is the day 1 concentrations of the theophylline data that
is included in the nlme/NONMEM.

## Usage

``` r
theo_sd
```

## Format

A data frame with 144 rows by 7 columns

- ID:

  Subject ID

- TIME:

  Time (hr)

- DV:

  Dependent Variable, theophylline concentration (mg/L)

- AMT:

  Dose Amount (mg)

- EVID:

  rxode2/nlmixr2 event ID (not NONMEM event IDs)

- CMT:

  Compartment Number

- WT:

  Body weight (kg)

## Source

NONMEM/nlme

# Nimotuzumab PK data

- ID:

  Subject ID

- TIME:

  Time (hrs)

- AMT:

  Dose Amount Keyword

- RATE:

  Rate

- DV:

  Dependent Variable, Nimotuzumab

- TAD:

  Time After Dose

- CMT:

  Compartment Number

- OCC:

  Occasion

- MDV:

  Missing DV

- EVID:

  Event ID

- WGT:

  Weight

- BSA:

  Body Surface Area

- AGE:

  Age

- HGT:

  Height

- DOS:

  Dose

## Usage

``` r
nimoData
```

## Format

A data frame with 441 rows by 15 columns

## Source

Rodriguez-Vera et al. 2015

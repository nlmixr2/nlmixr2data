# Parent/Metabolite dataset

Parent/Metabolite dataset

## Usage

``` r
metabolite
```

## Format

A data frame with 32 rows and 6 columns

- time:

  Time of observation

- y1:

  Parent Concentration

- y2:

  Metabolite Concentration

## Source

D'Argenio DZ, Schumitzky A, and Wang X (2009). "ADAPT 5 User's Guide:
Pharmacokinetic/Pharmacodynamic Systems Analysis Software".
